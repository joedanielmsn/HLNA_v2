# HLNA v2

A local-first desktop assistant platform built with a best-of-breed, source-code-first reuse strategy. HLNA v2 is independent of HLNA v1.

## Project documents

- [Development and source reuse plan](plan/HLNA_V2_DEVELOPMENT_PLAN.md)
- [Source component register and research findings](plan/SOURCE_COMPONENT_REGISTER.md)

## Current status

Planning and source research. No third-party source has been imported into the application tree. Foundation and specialist components remain subject to build, security, licence and performance validation.
